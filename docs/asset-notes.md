# 素材说明

素材库包含静态母版、序列帧图集、姿态参考、透明处理结果及切帧数据。图像素材使用图像生成与后续处理制作；各目录保留提示词和相关元数据，便于继续设计。

历史实验目录可能包含带底色原图、未采用的动作版本与当时的验证说明。运行时的实际映射以 js/design-art.js、js/sheet-data.js、js/zombie-sheet-data.js 为准。

当前植物待机以静态母版分层摆动为主；僵尸使用行走序列帧；选卡、铲子及待机小推车使用静态图。未删除保留的其他序列帧，便于逐帧学习与替换。

背景音乐源文件为程序合成的可选素材，当前版本不加载。音效在 js/audio.js 中实时合成。

# 豌豆射手16帧待机图集 v2

使用图像生成工具，基于已确认角色母版生成。最终采用修订后的16帧4×4纯呼吸图集，角色全部朝右，不混入眨眼/攻击。

- `peashooter-idle-sheet-v2.png`：原始透明图集，实际1254×1254。
- `peashooter-idle-sheet-v2.json`：按实际尺寸测得的逐帧裁切矩形与根部锚点。
- `index.html`：可暂停/步进/调速的真实逐帧预览；只做固定缩放和锚点对位，无交叉淡化、无程序化呼吸。
- `标准序列帧提示词.md`：中文可复用提示词、替换角色的方法、检查标准和实际产物限制。
- `generation-prompt.txt`、`refinement-prompt.txt`：实际使用的英文首轮与修订提示词。
- `reference-peashooter-design-v2.png`：角色母版。
- `validation.json`：16帧唯一性、主体边界、相邻帧与循环接缝的定尺寸渲染差异记录。

生成器未严格实现2048×2048目标尺寸和相同格内落点，因此按实际图附JSON定位数据；原PNG未被重排或重绘。这是经过对位检查的AI资产版本，仍有轻微造型差异，不宣称逐像素一致。此目录只新增素材与预览，没有替换当前游戏代码。

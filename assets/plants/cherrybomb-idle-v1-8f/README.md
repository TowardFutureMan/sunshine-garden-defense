## 动作设计

两颗樱桃为一个联动整体：上方连接梗与叶片大幅左右摆动（约10-15度），两颗樱桃小幅跟随倾斜（约4-6度），两张脸同步眨眼；果实底部接地区域为支点。

1. 中间睁眼 → 2. 左半 → 3. 左极限 → 4. 回中 → 5. 中间闭眼 → 6. 右半 → 7. 右极限睁眼 → 8. 回中接首帧。

## 去背方式

`background:"transparent"` 参数未生效（生成图为 RGB 实底双色棋盘格，右下角另带浅灰"AI生成"水印）。已用「背景双色接近检测 + 边缘连通域」算法去背：采样白/灰两种棋盘底色（L1 容差 45，水印像素被覆盖），仅与图像边缘相连通的水母/棋盘才算真背景；两樱桃与梗结之间封闭的棋盘格三角按「大岛含灰 / 高灰碎屑」规则删除，角色内部眼白与高光（不连边、低灰小岛）完整保留；alpha 高斯模糊 0.6px 柔边。深底复检无残留，水印区全透明，无串格。

## 已知事项（与动作计划的偏差）

- **支点漂移**：生成器把摆动做成了以底部为轴的整体摆，果实随帧序左移约 30-40px（设计为支点固定、仅梗叶摆动）。JSON 按实际位置记录，游戏接入时逐帧接地点对位。
- **眼睑时序**：第 5 帧双眼全闭、第 7 帧睁眼正确；但第 4 帧为睁眼（设计为半闭），第 6 帧为全闭（设计为半睁）——眨眼实际读作「第5、6帧连闭，第7帧睁」。
- **第 8 帧方向**：设计为自右侧回中，实际叶片仍向左倾（与第 2 帧同向），接首帧时有一次方向折返。
- 两行垂直基准相差约 15px（下行整体偏高），切帧已按实际区域记录。
- 生成未严格等格排版，切帧按实际角色区域（见 JSON），`renderScale≈0.204`（约75px游戏身高）。
- 当前游戏代码未修改；接入 `sprites.js` 的图片入口待与豌豆射手管线统一后处理。

# 其他植物八帧序列图提示词

用法：每次上传对应的静态设计图，复制下面该植物的完整提示词即可。每段已包含通用约束，不需要额外拼接。

固定的是角色设定、镜头和接地锚点；动作幅度、茎部弯曲和眼睑则必须按动作计划变化。不要同时要求“明显摆动”与“所有部件逐像素不动”。

如果纯文字生成仍不连贯，先生成8格姿态草图，确认“中间→左→中间→右”的弧线后，再把姿态图和静态母版一起交给AI。姿态图决定动作，母版决定外观。这比反复追加“更流畅”更具体。

## 向日葵

对应静态资产：`sunflower-design-v1.png`。

```text
以我上传的【对应植物静态设计图】为唯一角色母版，生成同一角色的8帧连续动画图集：4列×2行，按上排从左到右、再下排从左到右排列，目标2048×1024，每格512×512，真实透明PNG。
保留母版的角色结构、脸部轮廓、眼距、部件数量、材质、颜色、光照和相机视角。相机不动、不转、不缩放。按同一套角色模型推进动作，不要重新设计8个角色。始终保持母版朝向，射手炮口始终朝右；左右摆指画面中的茎部弯曲，禁止画成转头或镜像。
按该植物的根部或底部接地区域对齐各帧，不根据变化的包围盒逐格居中。动作应在约75像素高的游戏显示尺寸下也能辨认，不能只有几像素的随机抖动。摆动要形成中间→左侧极限→中间→右侧极限→回中间的清楚路线，并有对应的中间姿态。到极限自然减速再折返，末帧继续衔接首帧。
完整角色及动作最大幅度都要落在各自格子内，四边预留充足透明空间，无裁切、无相邻角色串格。不要地面、地面投影、文字、编号、格线、边框、水印或棋盘格背景。表情和动作必须按下面逐帧描述，不能随机分配。若另附姿态参考图，仅将其用于姿态、头部路线和锚点，外观与材质仍以静态母版为准。

【本角色动作与8帧顺序】
动作：花盘带动茎部左右轻摆，并眨眼。花盘与脸是一个整体，不能单独旋转花瓣或让脸在花盘上滑动。根部与底叶中心固定，摆动来自茎部弯曲；左右极限约10—12度，花盘水平位移约为植物高度的10%—15%。底叶尖可小幅跟随，整体不离地。
第1帧：中间位置，开心睁眼。
第2帧：向左摆到一半，茎部随之弯曲。
第3帧：左侧极限，花盘略倾，动作清楚可读。
第4帧：由左侧回中，眼睛半闭。
第5帧：回到中间，双眼完全闭合。
第6帧：开始向右摆，眼睛半睁。
第7帧：右侧极限，双眼睁开，花盘与茎部协调倾斜。
第8帧：由右侧回中，准备接第1帧。
保持金黄花瓣数量和形状稳定，不新增阳光、粒子或发光效果。
```

## 生成后的验收

- 先逐帧看姿态是否沿同一条路线推进；有左极限、右极限和回中的清楚过程，而不只是纹理抖动。
- 检查第4帧半闭、第5帧闭眼、第6帧半睁是否清楚，不能随机换成八张睁眼图。
- 用根部/底部接地对齐，保持固定显示比例，先按6—8fps真实切帧检查；不要用淡化或代码摆动掩盖源图不连贯。
- 既看放大图，也看游戏实际尺寸。动作不明显时增强关键姿态；衔接跳跃时修中间姿态，而不是一味缩小整个动作。
- 检查实际导出尺寸、8个角色的真实位置及完整性。AI未必精确执行等格规格，必要时记录实际裁切矩形与pivot；不要盲目按图片宽度四等分。
- 目标尺寸是制作要求，不是生成成功保证；原始图中的裁切、错向、丢部件不能靠播放速度修复。

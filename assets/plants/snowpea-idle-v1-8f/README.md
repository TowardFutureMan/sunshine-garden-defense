## 动作设计

冰蓝头部与脸、单根炮管为一个整体（炮管不单独旋转、不转头、不镜像），茎部弯曲带动头部沿弧线左右摆动；根部与底叶固定（仅第3帧后侧叶芽略有跟随）。左右极限头部水平位移约角色高度 15%，炮口始终朝右。

1. 中间睁眼 → 2. 左半睁眼 → 3. 左极限睁眼 → 4. 回中半眯 → 5. 中间睁眼 → 6. 右半全闭 → 7. 右极限睁眼 → 8. 回中接首帧。

## 生成与去背方式

- 图像生成工具 双图输入（`input_fidelity:"high"`，`background:"transparent"`），提示词见 `generation-prompt.txt`。
- `background:"transparent"` 未生效（生成图为 RGB 双色棋盘格实底），已用「背景色接近检测（近中性+亮度区间）+ 仅与图像边缘相连通域才算真背景」算法去背（scipy.ndimage.label），角色内部眼白/浅色高光不连边、未被误删；alpha 高斯模糊 0.6px 柔边，半透明像素以最近实心像素颜色去灰边。深色底合成复检无残留；alpha>128 连通域恰为 8 个（每角色一个）。

## 已知事项

- 眼睑时序与计划有偏差：计划为「第4帧半闭、第5帧全闭、第6帧半睁」，实际生成为「第4帧单眼半眯、第5帧睁眼、第6帧双眼全闭」——眨眼整体晚一帧。已按规则重抽一次（提示词强化帧精确措辞），重抽版在第3/7帧出现计划外的单眼眨、第4帧未半闭，偏差更大，故采用首版。播放时仍读作一次完整眨眼，节奏连贯。
- 第3/7帧左右极限就位，头部与茎弯清楚，后侧叶芽在第3帧有跟随；炮口八帧均朝右，冰蓝配色与冰晶位置稳定，未变绿、未增炮管、无喷冰/光效。
- AI 生成未严格等格排版，切帧按实际角色区域（见 JSON），游戏接入时逐帧根部对位；各列 pivot 横坐标一致（偏差 ≤9px，游戏尺寸下 ≤2px）。
- 当前游戏代码未修改；接入 `sprites.js` 的图片入口待与豌豆射手管线统一后处理。

## 动作设计

同一颗头带着上下两根炮管为一个刚体左右摆动并眨眼；根部固定，茎部随头部弯曲；炮口始终朝右，禁止转头或镜像；底叶固定。左右极限约 10—12 度，头部水平位移约为植物高度的 10%—15%。

计划顺序：1. 中间睁眼 → 2. 左半 → 3. 左极限 → 4. 回中半闭 → 5. 中间全闭 → 6. 右半半睁 → 7. 右极限睁眼 → 8. 由右回中接首帧。

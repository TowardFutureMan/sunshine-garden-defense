## 动作设计

花盘与脸为一个整体（花瓣不单独旋转、脸不在花盘上滑动），茎部弯曲带动花盘左右摆动；底叶与根部固定。左右极限水平位移约角色高度 10–15%。

1. 中间睁眼 → 2. 左半 → 3. 左极限 → 4. 回中 → 5. 中间闭眼 → 6. 右半 → 7. 右极限睁眼 → 8. 回中接首帧。

## 已知事项

- 本次 `background:"transparent"` 参数未生效（生成图为 RGB 实底棋盘格），已用「背景双色 + 边缘连通域」算法去背（保护角色内部眼白/高光不被误删），柔边 0.6px 高斯；深底检查无残留。若后续上线需要更高精度，可用 matting 服务逐帧重抠。
- 眼睑时序与设计有小偏差：第 3 帧生成结果为闭笑而非睁眼，播放时读作「左极限 → 眨眼笑」，节奏仍连贯。
- AI 生成未严格等格排版，切帧按实际角色区域（见 JSON），游戏接入时逐帧根部对位。
- 当前游戏代码未修改；接入 `sprites.js` 的图片入口待与豌豆射手管线统一后处理。

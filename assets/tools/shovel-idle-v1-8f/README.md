## 动作设计

铲子怠机待命：以刃尖接地点为唯一支点整体轻微左右摇摆；木柄与铲头是刚性整体（不弯曲、不变形、不分离、不增减部件）；左右极限约 7°，半幅约 4°；无手、无人物、无地面、无阴影、无表情；保持母版的手绘 3D 圆润材质与配色（蜜糖棕木柄、蓝灰钢铲头、暖金属箍、D 形抓手带透空孔）。

8 帧顺序：1. 中立直立 → 2. 左摆半幅（约4°）→ 3. 左极限（约7°）→ 4. 回中半途 → 5. 中立静止（节奏支点）→ 6. 右摆半幅（约4°）→ 7. 右极限（约7°）→ 8. 回中衔接第 1 帧。

## 已知事项

- **生成器输出偏差与校正**：图像生成工具 两次生成中，第 3、4 帧（左极限/回中）实际输出为右倾、左摆幅度不足，且刃尖支点逐帧向左漂移（非绕支点旋转）。重抽额度用尽后，最终图集在去背基础上做了**程序化姿态校正**：以每帧刃尖为支点刚体旋转至动作计划角度（误差 <0.3°），并统一 8 帧支点位置；仅旋转/平移，不改像素内容与配色。校正后路线严格为 中→左→左→回→中→右→右→回。原始未校正输出保留于 `shovel-wobble-8f-v1.png` 与 `shovel-wobble-8f-v1-r1.png`。
- **背景去背**：`background:"transparent"` 参数未生效（生成图为 RGB 实底棋盘格，三种浅灰阶）。已用「浅色低饱和背景候选 + 与图边缘相连通域才算真背景」算法去背（scipy.ndimage.label），保护了道具内部高光与木纹不被误删；alpha 高斯模糊 0.6px 柔边；深底复检无残留。
- **抓手孔**：母版 D 形抓手的握孔为透明设计，去背时将孔内被包围的背景区域（约 2100px/帧）一并置为透明，与母版一致。
- **红色支点标记**：生成器从姿态参考图抄来了刃尖下方的红色标记点（设计稿中无红色），已按严格红色阈值连同抗锯齿残晕一并清除。
- AI 生成未严格等格排版，切帧按 4列×2行 等格 + 实际 alpha 区域计算（见 JSON），游戏接入时逐帧刃尖对位；`renderScale` 0.162 对应约 60px 游戏显示高度。
- 当前游戏代码未修改；接入 `sprites.js` 的图片入口待与小推车管线统一后处理。

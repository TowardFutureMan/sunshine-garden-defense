## 动作设计

怠速原地状态：车身整体做 1–3px 上下震动（奇数帧中立、2/6 帧上移、4/8 帧下移），不打滑、不离地，轮底始终贴合同一接地线；两只可见轮辐每帧旋转 45°，8 帧一整圈（0/45/90/135/180/225/270/315°）。红色铲罩、灰色发动机、油箱盖、黑色手柄、轮毂金属盖的结构与配色不变；无烟、无粒子、无表情、无地面元素。

帧序：1. 轮辐0°·中立 → 2. 45°·上震 → 3. 90°·中立 → 4. 135°·下震 → 5. 180°·中立 → 6. 225°·上震 → 7. 270°·中立 → 8. 315°·下震接首帧。

## 已知事项

- 本次 `background:"transparent"` 参数未生效（生成图为 RGB 近白实底），已用「近白/中性软灰检测 + 边缘连通域 + 垂直开口剔除轮下接触线 + 填洞保护辐条 + 轮间区域清除」算法去背，柔边 0.6px 高斯；深色底与草坪绿底复检均无残留、无车底悬空口袋。
- 轮辐为 +/X 交替式转动（两条可见辐条旋转 180° 外观相同，生成器以 +/X 交替近似），非严格 8×45° 步进；两轮轻微不同步。
- 车身震动幅度极小（接近 1–2px），播放时可感知但较弱。
- 部分车轮带橙色角度标记点（源自姿态参考图的参考点，生成器一并沿用），属可接受的轻微穿帮。
- AI 生成未严格等格：上排接地线 y≈419、下排 y≈891–898，排间相差约 35–40px；切帧按实际角色区域记录（见 JSON），游戏接入时按 pivot 逐帧对位。
- 轮底保留约 2px 接触线残带（与轮毂相连，形态学无法剔除），呈轻微接地感。
- 当前游戏代码未修改；接入入口待与既有道具管线统一后处理。

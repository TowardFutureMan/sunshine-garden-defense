# 阳光庭院设计资产 · 2026-10-18

本套共 9 张单体透明 PNG：7 种植物、草坪小推车和铲子。

以已确认的豌豆射手设计为统一参考：圆润立体造型、手绘材质、左上方暖光、略俯视的侧面三分之四视角。新生成其余 8 张，豌豆射手沿用母版。均为 1254×1254 RGBA，已检查透明通道和完整主体。图中没有地面烘焙阴影。

使用图像生成工具，最终逐张提示词保存在同名 `.prompt.txt`，尺寸及可见边界记录在 `asset-manifest.json`。

打开 `index.html` 查看九宫格并点击独立原图；`contact-sheet.png` 是总览截图。本目录保存静态设计图，未生成新序列图。2026-10-18 已通过 `js/design-art.js` 接入当前游戏：选卡/种植预览使用静态图，场上豌豆保留原有连续待机动画，其余角色、小推车与铲子使用本套图片。已按每张图的实际包围盒设置尺寸和根部/车轮锚点。
